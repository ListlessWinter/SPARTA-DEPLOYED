# Rules

## Tokens

- **MANAGE TOKEN USAGE PROPERLY. DONT BURN OR WASTE UNNECESSARY TOKEN.** Read only the parts of
  files you need, search before reading, don't re-read files you just edited, don't re-run
  checks that already passed, and don't spawn agents unless asked.

## Permissions

- **Do not ask permission.** Make all edits, run commands and fix things directly. Ask only when
  a decision is genuinely the user's to make.

## Replies

- **Do not talk during the process.** No narration between tool calls, no "now I'll check X",
  no interim findings. Work silently.
- **Explain only at the end, in 1-3 short sentences.**
- **No tables, no preview images, no walkthrough of the reasoning** in the final message or
  anywhere else in chat.
- **Ignore all of the above when asked to.** A direct question, a request to explain, or a
  request for a table overrides it.
